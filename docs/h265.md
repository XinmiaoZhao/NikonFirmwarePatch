# H.265 码率 / H.265 bitrate

随 `--features video-quality` 安装，与 ProRes 画质共用一个安装组。H.265 提供原厂标称码率的 **100%、60%、45%、30%、20%** 五档，按视频拍摄菜单库保存。

## 使用方法

1. 选择 H.265 文件类型、所需位深和画面尺寸／帧频。
2. 打开“视频画质（H.265）”，选择档位。菜单同时显示该组合的目标 Mbps。
3. 根据场景细节与运动量选择码率。降低码率通常减小文件，编码器的实际输出仍随内容变化。

例如原厂标称 150 Mbps 的组合，五档菜单显示约 **150、90、68、45、30 Mbps**。Mbps 为十进制百万 bit/s；它是编码目标，不是实测文件平均值或卡速要求。

100% 使用星标，其余档位使用无星图标，回放信息对应录制档位。在非 H.265 模式下，该行显示百分比。ProRes 与 H.265 的星标按文件类型分别处理。

本版同时修正保护计时：避免先前部分 60% 的 4K50/60 组合意外变成全帧内编码。不同菜单库、i 菜单和回放中的组合行为，按[验证记录](validation.md)继续确认。

## English

`--features video-quality` includes H.265 and ProRes quality. H.265 targets **100/60/45/30/20%** of the stock nominal bitrate, stored per movie shooting bank. Select H.265, set the format and frame rate, then choose a tier in Video quality (H.265). The menu shows the corresponding target Mbps.

For a stock 150 Mbps mode, the displayed targets are approximately **150/90/68/45/30 Mbps**. Actual output depends on picture content; these are neither measured averages nor minimum card-speed requirements. Only 100% retains the star. Playback information follows the recorded tier, and non-H.265 modes display the percentage.

A protection-timer correction prevents certain reduced-rate 4K50/60 modes from unintentionally becoming all-intra. Combined menu-bank, i-menu and playback behavior follows the [validation scope](validation.md).
