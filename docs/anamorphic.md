# 反挤压显示 / Anamorphic desqueeze

随 `--features framing` 安装。视频拍摄菜单增加反挤压选项：**关闭、1.25×、1.30×、1.33×、1.50×、1.60×、1.80×、2.00×**，倍率按视频拍摄菜单库保存。

## 使用方法

1. 按录像需要选择文件类型、画幅和帧率。
2. 在“反挤压”中选择镜头的压缩倍率。
3. 录制时按反挤压后的比例构图；后期对原始录像使用相同倍率。
4. 回放其他镜头拍摄的片段时，切换到对应倍率或关闭。

该功能调整后屏／取景器显示窗口，以及 AF 框、亮起的对焦点、触控映射、放大导航和影片回放几何。**录像文件保留原始像素比例**，画幅仍由录像模式决定。回放使用当前倍率。

全选包已加入亮起对焦点的几何修正，机身试用暂未观察到绿点异常。全高画幅的边缘覆盖、小尺寸取景器及主体检测框仍缺逐项实测；验证范围见[当前记录](validation.md)。

## English

Bundled with `--features framing`. The menu provides Off, 1.25×, 1.30×, 1.33×, 1.50×, 1.60×, 1.80× and 2.00×, stored per movie shooting bank.

Choose the lens's squeeze factor, compose using the corrected preview, and apply the same factor in post. The function adjusts display windows, AF overlays including lit points, touch coordinates, magnification navigation and movie playback. Recorded pixels keep their original geometry. Playback follows the currently selected factor.

The tester reported normal lit AF points with the combined firmware. Edge coverage, small-viewfinder mode and subject-detection overlays still need individual camera checks. See [validation](validation.md).
